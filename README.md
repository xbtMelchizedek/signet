# Signet

Standalone typed-signer offer for the FLOP CLI `--signer` option
([flop-labs/network#337](https://github.com/flop-labs/network/issues/337)).

The CLI source in `flop-labs/flop-core` is not public, so this is not a fork
of that tree. The implementation is on the `issue-337-typed-signer` branch.
